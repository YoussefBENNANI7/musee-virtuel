# Images des œuvres : prompts à générer

Ce document contient un prompt par œuvre pour les 16 tableaux et photographies du musée de démonstration. Chaque prompt est cohérent avec le cartel déjà rédigé (artiste, date, technique, texte) et avec les proportions de l'œuvre dans le musée.

## Mode d'emploi

1. Copiez un prompt dans votre générateur d'images et choisissez le format indiqué (par exemple 4:3).
2. Vérifiez l'image : l'œuvre doit remplir toute l'image, à plat, sans cadre, sans mur, sans signature ni texte.
3. Enregistrez-la sous le nom de fichier indiqué. Les extensions `.png`, `.jpg` et `.webp` sont toutes acceptées.
4. Déposez les fichiers sur GitHub dans le dossier `public/museums/demo/images/` (bouton « Add file », puis « Upload files »).

## Règles de format

- **Taille** : au moins 2000 pixels sur le grand côté. Plus c'est grand, mieux le zoom fonctionnera.
- **Format** : si votre générateur ne propose pas le format indiqué, prenez le plus proche. Le musée adapte le cadre aux proportions réelles de l'image.
- **Cohérence** : plusieurs artistes ont deux ou trois œuvres. Leurs prompts partagent la même palette et la même facture ; gardez les images qui se ressemblent le plus entre elles.
- **Midjourney** : les prompts sont rédigés en phrases, pour Gemini, ChatGPT ou Flux. Sur Midjourney, ajoutez à la fin `--ar 4:3 --style raw` en remplaçant `4:3` par le format indiqué.
- **Licence** : vérifiez que votre générateur autorise l'usage commercial des images.
